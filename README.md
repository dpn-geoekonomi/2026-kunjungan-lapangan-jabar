# Kunjungan Lapangan Jawa Barat — KKDN 2026

Situs statis siap publish di GitHub Pages.

## Cara publish
1. Push isi folder ini (bukan folder `publish` itu sendiri, tapi isinya) ke root repo GitHub, atau ke folder `docs/`.
2. Di Settings → Pages, pilih source branch & folder yang sesuai.
3. Buka `index.html` sebagai halaman utama.

## Struktur
- `index.html` — rundown, isu strategis, daftar peserta, peta
- `tesco-indomaritim.html`, `vinfast-subang.html`, `catib-karawang.html`, `bumi-rudawi-subang.html` — profil tiap lokasi
- `map.html` — peta interaktif (dimuat lewat iframe di index.html)
- `styles.css` — token & komponen desain
